# PCでのテストプレイ（v0.8 / Excel更新版）

同じフォルダーの `index.html` をダブルクリックするか、PCのブラウザーで開いてください。

- 収録範囲：メンバーNo.01〜48、楽曲22曲（Codex実装用Excel準拠）。
- Node.js・Python・サーバーの準備は不要です。
- 最新版のChrome、Edge、Firefox、Safariなどを使用してください。
- CPU戦と、同じPCでP1/P2を切り替える手動対戦ができます。
- 別々の端末での通信対戦は未実装です。
- 再読み込みすると進行中の試合は消えます。

このHTMLはゲームソースから生成した配布用ファイルです。直接編集せず、リポジトリで `pnpm build:testplay` を実行して更新します。

CPUは公開済みの開始配置を基に、得点・勝敗・Appeal差・終了時疲労の順で配置を選びます。同時配置の相手の未確定配置は参照しません。大量のCPU対戦・統計出力はHTMLではなく、リポジトリの `pnpm simulate` を使用してください。
