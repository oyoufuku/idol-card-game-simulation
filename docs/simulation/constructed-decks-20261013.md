# 構築済みデッキ見直し案（2026-10-13）

この文書は旧12デッキ案の記録。現行構築は[2026-10-14の9軸＋3追加デッキ](constructed-decks-20261014.md)を参照。

**提案のみ。構築済み12デッキはまだアプリへ登録していません。検証用27チームの戦術支援見直しとは別枠のレビュー案です。本案の新規対戦は行っていません。**

## 森田のクールA採用について

変更前のクールAには森田ひかるが入っていました。旧 `ability-semantics.ts` の ownCool 判定が「自チームにクールとユーモアがいる」もクール利用能力に分類し、構築スコアへ+12していました。クール主体の利用と多属性併用を区別できていませんでした。最新balanced生成ではこの分類を修正し、全クール候補から森田を外しています。森田の基礎5だけの問題ではありません。

森田のAUTOはクールとユーモアの共存、BURST条件はCENTER/FRONTの3属性、Cはステージ属性種類数を利用します。本案ではクールから外し、条件が成立する多属性・チャージ疲労妨害・BURST連鎖へ置きます。これは構築上の配置先の変更案であり、能力変更ではありません。

## 27候補と12デッキの関係

検証用27チームは維持し、戦術・役割の見直しを実装。12デッキは別枠のオリジナル構築案で、27チームを置き換えない。27の自動生成スコアには勝率/WARを入力しない。以下のWAR参照は12案の手動調整だけに用いる。

## WARを加味した均一化の判断

- クール：旧クール内の藤吉cWAR +33.3（18件）、山下瞳月+31.3（32件）。CENTERコアの山下は維持し、支援に藤吉まで重ねる案を避け、向井・大園・小島の条件付き/防御役を試す。向井のクール内WARは欠測なので「クールでも弱い」と断定しない。
- チャージ：丹生のテーマ内+60（10件）、河田+50（14件）を序盤安定型の支援として参考にする。両者は基礎4/5で、チャージコアがBACKSにいる間も働ける。ただし小標本であり、別構築への同じ数値の移転は保証しない。
- 移動：疲労軽減型へ宮田を回す。旧疲労回復内+34.4（32件）と低総疲労の能力を参考にし、井上・遠藤理子と組ませる。移動軸での宮田WARは未測定。疲労攻撃型には旧移動内で藤吉+12.5、武元+31.3を参考にするが、各8件の暫定値。
- 疲労回復：宮田を移動側へ回した代わりに幸坂をBACKSの条件付き妨害役とし、有力な低疲労支援をこのデッキへ集中させない。井上・山口・丹生の回復戦術は維持する。
- 好花：旧バースト内cWAR -22（50件）を参考に、BURST連鎖から外して解除型へ。旧効果の田村WAR -26は新Bの強さ評価として流用しない。

これらは、戦術との相性を確認したうえでWARも参照してデッキ間の差を縮める案。総合WAR順位だけで振り分けず、テーマ内データと95%CI/欠測を区別する。カードWARの合計や平均はデッキ勝率の推定値にしない。最新の田村B・CPU・構築で同じ条件のローカル対戦を行うまで、強さが均一になったとは判断しない。

[各採用カードの総合/テーマ内WAR・標本数を含むJSON](constructed-decks-20261013.json)に参考値を保存する。勝率/WARデータはこの文書・提案JSONのみで、生成器は読み込まない。

## 構築の優先順位

1. 戦術の発動条件を実際の属性・ポジション・相方・楽曲で成立させる。
2. 味方同士の効果競合を防ぐ。利用と対策を混同しない。
3. 序盤のステージ5人と終盤の主役投入の両方を確保する。
4. その条件を満たす範囲で起用機会を分散する。均等化のために戦術不適合カードを混ぜない。

強いクール・多属性・疲労回復を、どの相手にも強い高火力支援だけで埋めない。弱かったチャージ・移動・対スキルは、現行の条件が成立する得点役・疲労対策・妨害役で補う。旧cWARが負のカードを機械的に「弱い」と判定して入れる方式にはしない。検証用27チームの生成スコアには勝率/WARを組み込まない。構築済み12案は、ユーザー指示に従い旧WARの値・編成別値・標本数を手動調整の参考にし、強い軸への有力支援の集中を減らす。WARを合計してデッキ勝率には換算しない。

今回の12案は9テーマを維持し、チャージ・移動・対スキルだけ2種類に分けた手動の構築済み候補です。追加テーマが必要な未起用者集団は、この案ではありません。全48人を1〜3デッキに収めました。ただしデッキに入る回数はステージ出場率やCENTER回数の均等を保証しません。

## 旧結果との関係と未検証点

提示された旧結果はクール67.5%、多属性63%、疲労回復62%、対スキル32.5%、チャージ31%、移動25%でした。本案の予想勝率ではありません。旧結果は旧田村B・通常/charge-archetype CPUの結果です。新田村B・BURST考慮CPU・構築変更をまとめて比較すると原因を分離できないため、ローカル検証ではCPU戦略を揃え、まず構築変更だけを比較する必要があります。

カードの強さ、デッキの勝率、弱いチームにならないことは未検証です。相性と95%CIを見て残す10〜12デッキを決め、全デッキを50%へ均すことは目標にしません。固定コアのWARが欠測である場合、0や弱さとは解釈しません。

ポジションは運用例であり、固定行動のCPUではありません。楽曲は選択した3曲から抽選されるため、特定ラウンドに特定曲が来る前提にしません。CENTER候補のCは同時には発動できません。効果が双方に及ぶ曲は自軍の不利益も記載します。

チャージ支援5人は竹内を例外に、自軍BACKS滞在/登場を主要条件にしない候補です。移動は山下葉留花・村井優・小西夏菜実の3コアを維持し、松田里奈・向井純葉・増本綺良を外しました。松田好花は低BURST運用の解除デッキへ移します。田村は相手BURSTを残す封殺デッキへ分離します。
