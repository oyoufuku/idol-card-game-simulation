# 構築済み12デッキ（2026-10-14）

9アーキタイプ各1個＋櫻坂選抜＋日向坂選抜＋指定8人。松田は松田里奈。検証用9軸×3＝27チームの生成ロジックは変更しない。カード・楽曲・CPU・ゲームルールも変更しない。

新しい構築の対戦は未実行。B条件の相性・L1/L2を手動調整の参考にした候補であり、勝率が均等になったと確定していない。WARは代替カードとの比較値なので合計してデッキ勝率に換算しない。比較件数と95%信頼区間、欠測を区別する。

今後のカード調整方針（2026-10-14ユーザー指定）：BURST発生率が極端に高い・低いカードをテコ入れ候補にする。通常/強制BURST、採用試合の発動割合/回数、RANDOM/構築、CPU・採用条件を区別し、発動頻度とBURST WARの勝利寄与は別指標にする。「極端」の数値基準は未指定。

## 起用機会

9軸だけの72枠で48人全員を起用し、各人1〜2回（24人が1回、24人が2回）に揃えた。追加3デッキはこの回数に含めない。これはデッキへの採用回数であり、CPUが実際にステージやCENTERへ出す頻度を保証しない。

## 今回の調整

- クール68%：クール利用コアを保ち、向井・小島・大園の条件付き/防御支援を採用。金村・小坂・森本などをさらに集中させない。
- BURST65.5%：中嶋・松田里奈・富田の連鎖を残し、森本/金村の追加集中を避け、正源司・石塚・武元で疲労条件と自軍BURSTを補う。
- 対スキル62.5%：的野・田村・村井を維持し、小坂の高い位置得点を重ねず、低BURST時の松田好花で別の得点手段を確保。JOYFUL LOVEで相手BURST継続効果を解除する一方、そのラウンドの田村AUTO/C・宮地のBURST継続効果も不発になることを織り込む。
- チャージ43%：固定3コア＋竹内を維持。金村・小坂・丹生・河田の序盤支援を厚くする。RANDOMのチャージカードWARは通常CPUの結果なので、CHARGE CPUでの弱さとは断定しない。
- 移動35%：3コアを維持し、CENTER固定の山下瞳月を外し、山崎で劣勢時の得点と敗北後支援、井上・遠藤理子・宮田で疲労対策。村井Cと山崎Cは使い分ける。
- 疲労付与31.5%：自軍を巻き込むキツネ/アザトカワイイを外し、森本を得点支援に回す。ユーモア中心でも非ユーモアの味方は自軍疲労付与の対象。
- 疲労回復46.5%：回復・軽減・低総疲労の連携を厚くし、小坂を回復で支える得点役にする。
- 多属性51%：ステージ/BACKS双方の3属性と、平岡用の3楽曲属性を確保する。相手のクール人数が多い時に相手加算が上回るStart over!を君はハニーデューへ変更。
- 属性メタ45.5%：相手クール人数と単独最多属性を核にする。河田/谷口Cを止める静寂の暴力を外す（山下瞳月Cは同曲で止まらない）。PLAIN運用と属性人数参照は両立しないのでCENTERを使い分ける。

## 選抜2デッキの見直し

櫻坂はステージ出役の得点・妨害が主戦術。Unhappy birthday構文は登場を要求するため井上・幸坂などの補助運用とは噛み合いにくく、日向坂曲の君はハニーデューも外す。Start over!でクール出役を加算、静寂の暴力で山下瞳月Cを残し相手Cを止め、UDAGAWA GENERATIONで3属性を維持して相手を妨害する。先行時に相手を助ける何歳の頃に戻りたいのか？は外す。BACKS固定自体を主戦術にせず、配置の追加ルールは作らない。

日向はキュート4人・ユーモア4人、選択曲もキュート2曲・ユーモア1曲。最多属性妨害、属性数、低BURST時の得点を利用する。森本の追加クールは能力どおり発生する。櫻坂選抜のクール主体とは別の路線にする。両選抜は所属グループの曲だけを選び、グループ曲ではないMCタイムは選抜には採用しない。他の9軸や指定8人デッキの選択候補は変更しない。

## 実行・互換性

`--archetype-selection constructed --cpu-strategy charge-archetype --matches-per-matchup 50`で実行する。同型込み78組×50＝3,900試合。CHARGE CPUはチャージ1デッキだけ、ほか11デッキは通常CPU。指定8人は全員固定、選抜は所属を保った合法replacementに限定する。

旧構築のcheckpointとは構築仕様・plan hashが異なり混在できない。実行中のB条件L3は旧commitで継続する。L3を含む旧結果は保持し、最新構築の検証は別の出力先で行う。
