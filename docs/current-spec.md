## 共通進行

得点は通常勝利1、差10以上2、R7はそれぞれ2/3。引き分け0。最終ポイント同点なら7ラウンド累計Appealで判定。

位置AppealはCENTER+2、FRONT+1、MIDDLE+0。疲労0〜2は0、3〜4は-1、5〜6は-2、7以上は**-3**。桜月はこの減少量を2倍。疲労減算後のAppeal下限0。通常終了時疲労はCENTER+3、FRONT+2、MIDDLE+1、BACKS-2（最低0）。遠藤理子のAUTO有効時は疲労増加を1軽減。

R1初期配置はBACKSからの登場・前ラウンドからの移動に数えない。以後は前回パフォーマンスの位置と比較する。全く同じ位置の維持と、CENTER/FRONT/MIDDLE/BACKSという位置種別は区別する。

## ラウンド順序

1. 前回予約ボーナス、開始時AUTO（森本のseed付きランダム属性追加）。
2. 前回終了時BURSTの継続効果・位置固定・属性変更を保持（この時点では再発動しない）。
3. 楽曲を決定、曲変更・曲属性変更を反映。公開済み状態を保存。
4. 両チームが配置決定。CPUは保存した公開状態だけを見て独立に決定する。
5. 登場を確定。JOYFUL LOVEのBURST状態解除、CENTERによるPLAIN/一時基礎値、ステージ入りチャージ消費を解決。
6. 楽曲疲労→P1/P2順のAUTO/CENTER前処理→両者の共通Appeal計算。
7. スコア、累計Appeal、位置/シンメ/疲労などの条件用履歴を記録。
8. キツネの現在疲労2倍→位置疲労/BACKS回復→敗北CENTER→BURST終了時疲労。BURSTで予約した終了時リセット等を処理。
9. BACKSチャージ・竹内の付与、連続履歴更新、両チームのBURST条件を判定し、発動候補を保存。
10. 今回までのパフォーマンス限定状態を解除し、次回の基準位置を保存。
11. 保存した候補をP1→P2、各チームの選出順で1枚ずつ通常BURST。疲労0と即時B効果を実行し、強制・反応BURSTも1枚ずつ処理。小島・的野・幸坂・松田好花およびチャージ3人の人間側対象は各カードの発動直前に選択する。発動後は次のパフォーマンス終了まで継続効果・固定を保持。R7終了時にも条件判定・即時効果は実行するが、得点・最終勝敗は確定済みで変えない。

ブラウザーの演出は、共通エンジンが適用した変化を任意の記録機能で観測して表示する。パフォーマンス時の表示順はP1のMIDDLE L→MIDDLE R→FRONT L→FRONT R→CENTER、各カードA→B→C、その後P2・控え・終了時効果。終了時BURSTは1枚ごとに実処理と演出を行い、演出が終わってから次のカードへ進む。パフォーマンスのA/B/Cは計算済みの変化を順番に再生し、即時B対象選択ではエンジンを途中停止する。この表示順は上記のゲーム処理順を変更しない。演出の有無による状態・得点・ログ・乱数の一致を回帰テストで確認する。CPU候補評価は演出を記録しない。CLIの実試合はチャージ回復の観測に共通の効果記録を使用する。上部の横長ナレーション帯は発動者告知約2.6秒→対象ごとの説明約3.2秒。BURSTは約4.6秒の中央拡大・反転のあとB効果の説明へ進む。表示のみの変更でタイミング・RNG・得点は変えない。

通常BURSTは原則1人1試合1回。疲労0、次の1パフォーマンス中発動。強制BURSTは通常使用済みでも可、B効果を実行し通常使用済み状態は消費しない。リセットでも累計回数は維持。

## 盤面とAppeal内訳の表示

相手の盤面は自分の上側に180度反転して表示する。配置中は前回の公開済み配置（初回は初期配置）、実行後は確定した配置を使う。横持ちではBACKSをステージの横に並べる。相手BACKSは初期状態で開き、3人のカードを表示する。タップで詳細を確認でき、見出しで折りたためる。カード詳細は正立表示。スマホの基本UI倍率はデスクトップの約75%とする。横持ちのカードは画面幅いっぱいへ引き伸ばさず固定サイズとし、自分・相手のステージ10枚は同じ大きさ、BACKS6枚は同じ大きさとする。スマホではステージを通常57×85.5 CSS px、BACKSを48×72 CSS pxで表示する（狭い画面のステージは54×81 CSS px）。すべて共通の2:3カードテンプレートと画像枠を使い、能力文は盤面では小さく表示する。左側には拡大カードと小さな文字の能力全文を表示し、必要な部分だけスクロールして読める。横持ちでは左の拡大カード枠を広げ、盤面とBACKSの幅制限を緩めてフィールド左右の余白を減らす。表示倍率に合わせて画面の高さを補正し、左右それぞれでスクロールできる。ナレーションは画面最上部の横長帯に表示し、ヘッダーや設定の上に重ねる。実測した帯が盤面にかかる分だけ盤面の上に余白を確保する。対象カードを表示領域の中央付近へスクロールする。演出設定の開閉でヘッダーを拡大しない。主要操作ボタンはステージの見出しにまとめ、カードの上に重ねない。楽曲効果は折りたたみ式で全文を読める。長い能力文は「スキル効果を確認」で開閉する。表示の反転はスロットIDや対面対象の計算を変更しない。

詳細Appeal計算に発動者・スキル種別・効果文・適用値の任意メタデータを添える。複数Bによる固定減少は既存の合算・軽減計算を維持し、合算値に全発動者を表示する。CPUの簡略計算は内訳を生成しない。予測表示は自チームの編集中配置と相手の公開済み配置を使用し、未確定の相手配置を参照しない。

全体・複数人の効果は発動者・スキル・処理タイミング・効果の種類・増減の方向ごとにまとめ、対象カードを同時に演出する。全員/各チーム/ステージ/BACKSの全員であればその範囲を表示し、一部のみの変化なら対象人数を表示する。数値の違いは実適用値を保持する。自動進行OFFでは説明、BURST待機、BURST反転後の表示をユーザーの「次へ」まで保持する。スキップ・手動対象選択は引き続き可能。設定は表示だけに作用し、ルール・CPU・計算結果を変えない。

小田倉Bのクール追加は終了時発動から次パフォーマンスの予測・実計算まで保持される。元の属性も残り、相手ステージ5人のクール数がAUTO減少へ反映される。次パフォーマンス終了時に解除し、PLAINの優先・相手効果無効・JOYFUL LOVEでの即時属性変更保持は従来どおり。
